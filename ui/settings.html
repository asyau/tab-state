  2. 2 Add Tab State to your assistant

    Plugin For Claude Code, the terminal app you start with claude. Run these inside it, then restart the session:

    /plugin marketplace add asyau/tab-state
    /plugin install tab-state@tab-state

    Using the Claude app on Mac or Windows? Plugins don't work there — . Claude Code must run on this computer: cloud sessions (claude.ai/code, or a cloud session in the app) run on a remote machine that can't see your tabs, and don't support /plugin.

    Claude Code starts the Tab State server itself whenever it needs it — nothing else to install or keep running. Needs Node.js 18+. Check it with /mcp: tab-state should show as connected.

    Plugin For OpenAI's Codex (CLI, IDE extension or app). In a terminal:

    codex plugin marketplace add asyau/tab-state
    codex plugin add tab-state@tab-state

    Works in the Codex CLI, IDE extension and app. Codex starts the server on its own; needs Node.js 18+. Check it with codex mcp list.

    One-click install The Claude app for Mac or Windows:

    1. Download Tab State for Claude Desktop (tab-state.mcpb)
    2. Double-click the downloaded file — or in Claude Desktop open Settings → Extensions and drag it in — then click Install.
    3. Tick Share my tab history in step 1. Claude starts Tab State itself; this page turns green.

    Nothing else to install — Claude Desktop includes everything it needs. The /plugin commands are for Claude Code (the terminal app) and don't work here.

    Build it yourself instead

    From your copy of the repo (needs npm install -g @anthropic-ai/mcpb once):

    cd tab-state/mcp-server && npm install && npm run build:mcpb

    Then install mcp-server/dist/tab-state-mcp-1.0.0.mcpb as above. Or add this to claude_desktop_config.json (use your real path):

    "tab-state": {{ "command": "node", "args": ["/path/to/tab-state/plugins/tab-state/server/tab-state-mcp.mjs"] }}

    ChatGPT can only reach servers on the internet, so this one takes a few more steps (developer mode on Plus, Pro, Business, Enterprise or Education, on the web):

    1. Start remote mode:
      cd tab-state/mcp-server && npm install && npm run remote
      It prints a private URL ending in /mcp/<token>.
    2. Expose only that port over HTTPS, e.g.
      cloudflared tunnel --url http://127.0.0.1:8766
    3. At chatgpt.com/plugins, create a developer-mode app with https://<your-tunnel>/mcp/<token> and No Authentication.

    Anyone with that full URL can read your tracked tabs while the tunnel runs — treat it like a password. Only the read-only tools are exposed; sync is never reachable through it. Security details

    Any MCP client that can launch a local (stdio) server — no npm install needed:

    node /path/to/tab-state/plugins/tab-state/server/tab-state-mcp.mjs

    Tools: search_tabs, list_tabs, get_tab, get_session_recap. Several assistants can run at once — they share the same data.

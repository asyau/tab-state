Settings

Tab State works with no setup. These options tune the summary provider, how tabs are sorted, and a couple of optional extras.

Summary provider

OpenAI-compatible API

Ollama: start it with OLLAMA_ORIGINS="chrome-extension://*" ollama serve so the extension is allowed to call it.

Anthropic API

With a cloud provider, page titles, descriptions, and your reading stats (not page contents) are sent to that provider. API keys are stored unencrypted in this browser profile.

Saved

How tabs are sorted

All fields in seconds (scroll fields in %). Changes apply immediately.

Saved

AI-assisted tab grouping

Tab State's main view always sorts by how you engaged with a page, not what it is — this is an optional extra, never automatic.

Today's check-list

Sites you want a daily reminder to check. Add one from a tab's card on the dashboard.

Your data

Everything is stored locally in this browser. Closed tabs are forgotten after 7 days.

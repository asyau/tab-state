Settings

Tab State works with no setup. These options tune the summary provider, how tabs are sorted, and a couple of optional extras.

Summary provider

OpenAI-compatible API

Ollama: start it with OLLAMA_ORIGINS="chrome-extension://*" ollama serve so the extension is allowed to call it.

Anthropic API

Tab State Pro (hosted)

No API key to manage — summaries run through a small proxy that holds the key for you. This needs a Worker URL from your own deployment; see pro-proxy/README.md in the repo (this isn't a public service you can just turn on).

With a cloud provider, page titles, descriptions, and your reading stats (not page contents) are sent to that provider. API keys are stored unencrypted in this browser profile.

Saved

How tabs are sorted

All fields in seconds (scroll fields in %). Changes apply immediately.

Saved

AI-assisted tab grouping

Tab State's main view always sorts by how you engaged with a page, not what it is — this is an optional extra, never automatic.

MCP server (local, optional)

Runs entirely on your machine — see mcp-server/README.md in the repo to install and connect it to Claude Desktop or Claude Code. Nothing is sent anywhere except to that local process.

Today's check-list

Sites you want a daily reminder to check. Add one from a tab's card on the dashboard.

Your data

Everything is stored locally in this browser and kept forever — see the full history on the History page. A purged tab is the one exception: it's deleted about an hour later.
